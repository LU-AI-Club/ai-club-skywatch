# Live validation checklist
 
When the detector starts running on live data instead of the September
recording, we check these numbers to make sure nothing broke.
 
| What we check            | September recording | Live |
|--------------------------|---------------------|------|
| Total alerts in an hour  | 3                   |      |
| HIGH alerts              | 1                   |      |
| MEDIUM alerts            | 0                   |      |
| LOW alerts               | 2                   |      |
 
## What we're hoping to see
Numbers close to the September column.
 
## What would worry us
- Way more alerts (like 200 instead of 3) — the detector is too sensitive
- Zero alerts for hours — something is broken
- Mostly HIGH alerts — our thresholds are wrong
