# Spoofing fixtures — the shared test corpus

Test data for the spoofing detector. **Do not hand-edit these files.** They are
generated by `scripts/generate_spoofing_fixtures.py`; change the script and
re-run it from the repo root:

```bash
python scripts/generate_spoofing_fixtures.py
```

Every file is a JSON list of observation dicts matching
[`AdsbObservation`](../../models/observation.py). Keys beginning with `_`
(`_label`, `_note`) are annotations — `AdsbObservation.from_dict` ignores them.

Load one in a test with the helper in `tests/conftest.py`:

```python
def test_teleport_fires(observations_from):
    obs = observations_from("spoofing/pos_teleport.json")
    ...
```

## Positives — these must produce a detection

| File | What it contains | Gate it should trip |
|------|------------------|---------------------|
| `pos_teleport.json` | One position displaced 47.3 nm sideways; implies ~34,000 kt | `teleport_v1` |
| `pos_speed_contradiction.json` | Positions imply 450 kt, `ground_speed_kt` reports ~306 kt (32% off) | `speed_delta_v1` |
| `pos_vrate_contradiction.json` | Claims +3500 fpm while altitude never changes | `vrate_delta_v1` |
| `pos_impossible_turn.json` | 95° of heading change in 5 s = 19°/s | `turn_rate_v1` |
| `pos_impersonation.json` | Two transmitters ~130 nm apart sharing one `icao24`, interleaved in time | `coexistence_v1`, `pingpong_v1` |
| `pos_gap_takeover.json` | 45 s of silence, then the track resumes 120 nm off course | `reappear_v1` |
| `pos_integrity_collapse.json` | `nic` pinned at 0 for 90 s | `nic_floor_v1` |
| `pos_registry_mismatch.json` | A light-aircraft registration flying FL350 at 450 kt | `registry_mismatch_v1` |

`pos_impersonation.json` also trips the physics gates. That is expected and
correct: one ID in two places looks like repeated impossible jumps. The
*ping-pong pattern* — hops that reverse direction — is what separates
impersonation from a one-way jump.

## Negatives — these must produce NO detection

| File | What it contains | Gate it must not trip |
|------|------------------|-----------------------|
| `clean_track.json` | An ordinary airliner: 450 kt, FL350, straight and level | any |
| `neg_tailwind_cruise.json` | 780 kt over the ground in a jet stream — fast but real | `teleport_v1` |
| `neg_standard_turn.json` | A rate-one turn at 3°/s | `turn_rate_v1` |
| `neg_legal_descent.json` | −3000 fpm, with the altitudes agreeing | `vrate_delta_v1` |
| `neg_benign_gap.json` | 125 s of silence, resuming inside the reachable circle | `reappear_v1` |
| `neg_close_formation.json` | Two aircraft close together with **different** IDs | `coexistence_v1` |
| `neg_brief_nic_dip.json` | `nic` dips to 1 for 20 s, then recovers | `nic_floor_v1` |
| `neg_ground_vehicle.json` | An airport vehicle: 12 kt at field elevation, wandering heading | any |
| `neg_sparse_track.json` | Only 2 observations — too little evidence; abstain | any |

## Conventions

- `_label` is `positive:<gate>` or `negative:<gate>`; the evaluation script
  reads it to know the right answer.
- All tracks are near Lynchburg, VA and start at `2026-09-01T00:00:00Z`.
- Generation is fully deterministic — no randomness, no clock reads — so
  re-running the script produces byte-identical files.
